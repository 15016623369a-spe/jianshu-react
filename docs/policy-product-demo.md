# 见数 · 政策调查验收

运行 `bash scripts/demo.sh` 后打开[政策调查](http://127.0.0.1:28501/?workspace=policy-exploration)。自然语言调查是默认视图。文档库、按条件查口径、日期分段和多源实验都从这一页进入。

## 用内置政策比较两个月

1. 保留预填问题，点击「开始调查」。
2. 华南电水壶 2026 年 10 月的净营收为 **¥292.80**。11 月按当月口径为 **¥246.40**，按 10 月口径重算为 **¥252.00**。页面展示实际差额 **−¥46.40**、统一口径差额 **−¥40.80** 和两种差额之差 **−¥5.60**。
3. 展开「核对实际口径的条款和 SQL」和「核对统一口径的条款和 SQL」，查看公告、账本和参数。调查过程显示实际检索阶段和模型调用次数。
4. 点击「载入证据补查示例」，使用自动模式运行 11 月到 12 月的案例。系统根据旧称找到正式公告，排除同名参考问答。词面补查命中后模型调用为零。[检索与引用评测](policy-grounding-evaluation.md)

## 上传政策，核对版本前后差异

1. 在「文档库」选择政策，上传 [第一版示例](../examples/demo/policy-upload-v1.md)。示例采用 UTF-8 Markdown，`##` 标题下有文号、商品、地区、生效期、账本和退款上限。
2. 回到自然语言调查，选择已上传政策，问「华南电水壶 2026 年 10 月净营收是多少？」。结果为 **¥292.80**，来源显示第 1 版。调查只使用所选文档，所需转引文件也需要选入。
3. 在同一文档下上传 [第二版示例](../examples/demo/policy-upload-v2.md)。退款上限改为每单 ¥3，最新版本重新运行得到 **¥294.80**。旧版仍可打开查看原文。
4. 在认证部署下，上传者可将文档分享给指定账号。被授权账号可读取版本和用于调查。上传者可更新版本和撤销读取授权。仅本机演示使用单账号模式。

上传最大 64 KiB，单份文档最多 40 个标题段落。单账号最多上传 40 份文档，每份最多 20 版。一次调查可选最多 8 份资料。当前调查使用内置商品目录和演示账本，范围为一个地区、一个商品和最多两个自然月。上传资料在本机检索和解析。

## 用生产配置验收

```bash
bash scripts/policy_release_smoke.sh
```

脚本在本机启动独立 HTTPS 环境，以两个临时账号检查文档与计算权限、历史版本、撤权、跨站访问及 API 重启后的持久性。[正式环境配置和备份恢复](release.md)
