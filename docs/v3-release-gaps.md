# V3 发布条件与剩余项

日期 2026 年 11 月 19 日。

## 结论

```text
M1–M5 核心验收：已通过
M6 本地生产配置 HTTPS 冒烟：已通过
正式发布：尚未满足
```

当前最多是 **本地生产配置验收通过**，还不是可对外发布版本。

## 一、必须完成（P0，阻断发布）

### 1. 真实部署环境

```text
[ ] 真实域名或正式内网域名
[ ] 受信任证书（非 Caddy 本地 CA）
[ ] 目标主机 Compose 实际部署
[ ] 生产用户文件（Caddy 密码哈希）
[ ] 生产环境 .env.production.local
[ ] 固定镜像 tag/digest
```

### 2. 生产权限验收

```text
[ ] 两个真实账号走 HTTPS 上传/分享/读取/撤权
[ ] v3 调查历史、报告/CSV 导出在撤权后的权限
[ ] 伪造身份头/匿名/错误密码
[ ] 重启后版本和 ACL 持久化
```

现有 HTTPS smoke 覆盖了 v2 政策文档；v3 历史/导出/retail 还没并入同一生产冒烟。

### 3. 外部试点

```text
[ ] 1–3 名未参与开发的试用者
[ ] 用自己的典型问题完成 提问→核对原文→历史→导出
[ ] 记录中断位置和改写需求
[ ] 金额/版本/权限错误阻断发布
```

### 4. 备份、恢复、回滚

```text
[ ] 生产状态卷真实备份
[ ] 独立 Compose 空卷恢复
[ ] 恢复后调查历史/文档/ACL 核对
[ ] 前一版镜像回滚演练
[ ] 回滚后 HTTPS + 双账号冒烟
```

本地脚本和测试已有；目标主机演练没有。

### 5. 发布归档

```text
[ ] v3.0.0 tag
[ ] 镜像 digest 清单
[ ] 数据快照/文档版本
[ ] M5 评测报告归档
[ ] 三分钟演示录制
[ ] 已知限制和隐私/数据保留说明
```

> **代码和评测已经接近发布，但真正阻断发布的是目标环境部署、真实证书、外部试点、生产备份/恢复和回滚演练；这些必须在目标主机完成，不能由本地 Compose 冒烟替代。**
