# 简历项目描述参考

## 版本 A：偏 Agentic RAG

**见数｜垂直政策/手册/零售 Agentic RAG（个人项目）**

- 设计并实现 Evidence-gated Agentic RAG：范围解析 → 文档/公告检索 → 证据缺口判断 → 补查或拒答 → 只读 SQL → 金额/引用核验。
- 支持 Markdown/HTML/PDF/DOCX 版本化入库，保留页/段落引用、ACL、历史与 Markdown/CSV 导出。
- 建立 150 题多域评测：模型兜底 150/150，错误出数 0，Citation precision 100%，正常路径 P95 4.45 ms。
- 301 项自动测试；通过生产配置 HTTPS 双账号冒烟；实现结构化观测、备份恢复和并发有界拒绝。

## 版本 B：偏数据/后端

**见数｜Text2SQL + RAG 调查工作台（个人项目）**

- 将自然语言问题拆成范围、政策版本、账本、SQL 与证据链，保证每个金额可复查。
- 设计版本化文档库与 ACL；支持政策/手册/零售三个域共用一套检索、证据和历史。
- 引入证据门槛与冲突/循环/缺覆盖拒答，避免半截金额。
- 建立 150 题评测和延迟报告，持续回归 301 项测试。
