# 独立政策文档留出与检索评测

政策调查的默认模式依次读取精确匹配、按词面检索原称和模型改写。模型只在词面候选缺少可验证链接时提议新检索词。引用仍需通过原文中的旧称或转引关系、商品、地区、生效期和适用性验证。

## 语料和题型

使用与产品演示和上一轮评测分离的合成语料，包含 **12 个商品族、53 段 Markdown 政策与公告、30 道题**。题型覆盖月中切换、跨年比较、统一口径重算、多跳公告、同名过期公告、FAQ 干扰、等权冲突、循环引用、覆盖缺口、无订单和需要澄清的问题。订单及退款台账也独立于演示数据。

两类难例的正式公告正文明确接续旧规，但原称词面检索的前五个候选被同主题 FAQ 和培训材料占据。两种检索模式使用相同的权威判定规则。原称改写能否恢复证据，取决于新查询是否检索到明确写有接续关系的正式公告。还有两题的旧称能通过词面直接找回，用于验证自动模式可以跳过模型。

金标准在运行前固定。评测程序直接读取订单与台账，用已标注的口径独立重算金额，并验证预期文号唯一。每组对同一题集跑三轮，按固定随机种子交错执行。90 次运行对应 30 道独立题，三轮用于检查结果稳定性。

## 指标

- **候选 Recall@1、@3、@5** 以真实口径的每个时间段及其引用链条目为单位。候选在原始排序中的相应名次内才记为命中，跨分段时要覆盖整个金标准时间段。首轮仅统计已执行的精确检索，最终统计所有执行过的阶段。某条路径提前停止时，后续没执行的检索计为未命中。权威筛选后的选中率另计。
- **引用精确率和召回率** 以计算场景、时间段和文号为单位。正确项需要命中金标准文号，且标题、文件、行号和完整引文匹配原文。精确率分母是返回的引用数，召回率分母是所有应当返回的引用数。拒答没有错误引用时，仍会因为缺少应有结果拉低召回率。
- **任务通过** 同时核对商品、日期、政策范围、实际和重算金额、引用与 SQL 参数。预期停止的题检查状态、理由和是否执行 SQL。延迟含模型往返，评分开销另计。轮次汇总使用 nearest-rank P95。

## 三轮实测

| 指标 | 固定精确检索 | 确定性词面补查 | 自动词面优先 |
| --- | ---: | ---: | ---: |
| 任务通过 | 72/90 | 78/90 | **90/90** |
| 金额、引用与 SQL 均正确 | 48/66 | 54/66 | **66/66** |
| 正确停止或澄清 | 24/24 | 24/24 | 24/24 |
| 错误出数 | 0 | 0 | 0 |
| 首轮候选 Recall@5 | 87.23% | 89.36% | 91.49% |
| 最终候选 Recall@1 | 51.06% | 51.06% | 59.57% |
| 最终候选 Recall@3 | 87.23% | 89.36% | **100%** |
| 最终候选 Recall@5 | 87.23% | 89.36% | **100%** |
| 权威选择召回 | 82.98% | 89.36% | **100%** |
| 引用精确率 | 100% | 100% | 100% |
| 引用召回率 | 65.75% | 78.08% | **100%** |
| 模型调用 | 0 | 0 | 12 |
| Token | 0 | 0 | 3,816 |
| P95 | 3.86 ms | 4.64 ms | 1.03 s |

候选和权威选择的分母均为 141 条检索依据。固定、词面和自动模式分别找回并返回正确引用 144、171 和 219 项，引用召回率分母为 219。三种模式的引用精确率分母分别为 144、171 和 219。

自动模式比纯词面多完成 **12 次**，对应四道题各三轮。每一次模型兜底均对应前五个词面候选遗漏的可验证公告。另有六次旧称检索直接用词面完成。自动模式累计 **78/90** 次请求零模型调用。

另用同一冻结题集单独跑三轮只调用模型补查的对照，结果同为 **90/90**，用 18 次模型调用和 5,704 token。词面优先共省 6 次调用和 1,888 token，用量减少 **33.1%**。两次运行分开执行，延迟可受当时模型服务波动影响。

上一轮 11 道主评测题只有可直接查原称的改名公告，词面和模型均通过。本轮加入排名受干扰、且存在可核验接续条款的材料，得分应在新题集的三个对照组之间比较。

样本范围是合成的结构化交易数据与正式关联可核验的政策正文。结果适用于这批复杂度和文档形式，真实企业资料中的召回效果仍需独立评估。

## 复跑

```bash
python -m evaluation.run_policy_grounding --modes fixed lexical auto --repeats 3 --env-file /path/to/.env --output-dir /path/to/fresh-results
python -m evaluation.run_policy_grounding --modes model --repeats 3 --env-file /path/to/.env --output-dir /path/to/model-only-results
python -m evaluation.run_policy_grounding --modes fixed lexical --repeats 1 --output-dir /path/to/offline-results
```

输出包括逐题评分、汇总和文件指纹。离线复跑也可以用 `--offline` 观察默认路径在无模型的环境下在哪些例子停止。
