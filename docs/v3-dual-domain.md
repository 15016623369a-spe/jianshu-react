# V3 双域调查

V3 从当前主线继续实现。`v2.0.0` 保留为可回退的冻结检查点。

## 在同一页面验收

打开[调查工作台](http://127.0.0.1:28501/)，进入「自然语言调查」。

- 选择「政策计算」，运行默认问题。应得到实际差额 **−¥46.40**、统一口径差额 **−¥40.80** 和两者之差 **−¥5.60**。可查看适用政策、账本与只读 SQL。
- 选择「手册问答」，用演示手册提问「怎样连接 Wi-Fi？」。第 1 版说明连接成功时指示灯为蓝色，第 2 版为绿色。展开「查看出处」核对文件、版本和行号。
- 在「文档库」切换到「产品手册」，上传 [Markdown 第 1 版示例](../app/manual_corpus/guide-v1.md)（也支持 HTML）。回到调查页，选择「文档库手册」和该版本即可引用上传内容。在认证部署中，上传者可以共享和撤回读取权限。

## 共用接口

`POST /api/v3/investigations` 按请求的 `domain` 路由。政策计算沿用原有的口径解析、证据核验与只读执行。手册域使用章节标题匹配，输出选定版本的原文。两条链统一返回出处、版本、行号和引用正文。回答需要可核对的来源。

两种上传资料共用文档版本与读取权限的实现，通过各自的文档库维护。读取时在同一事务内核验当前账号和所需版本。政策仍使用原有数据文件，手册存入独立的 `manual_documents.sqlite`。当前的两个手册版本均为演示资料，上传入口支持 UTF-8 Markdown/HTML。文本 PDF 和新手册留出评测属于后续入库工作。
