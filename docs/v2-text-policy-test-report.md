# 见数 V2 · 政策正文检索与多跳评测

2026 年 11 月 15 日。政策探索的默认模式是固定快路径、已核验计划缓存和有上限的重规划。普通「政策问数」仍使用原固定流程。上一版的实验结果保留在[政策探索与计划缓存历史报告](v2-policy-exploration-report.md)。

## 从正文取证

- 按 Markdown 标题切分段落，使用中文二元词片段做词面召回。标题匹配权重更高。政策候选按产品、类目、地区和完整生效区间缩小范围，产品专项优先。按正文引用的《标题》或「专题最新公告」继续检索。候选同等适用时停止。
- 账本、逐笔扣减上限、起止日期和转引方式均从正文可见的条款抽取。Markdown 没有隐藏 JSON 或 front matter。文号用于引用定位、检测循环和区分计划适用范围。独立产品目录、订单和台账继续按业务数据保存。
- 使用最终条款指定的 `orders`、`refunds` 或 `chargebacks`。核对外部台账字段后执行参数化只读 SQL。同一订单的退款或争议扣回先归集，再应用单笔上限。返回完整引用链、原文、文件行号、SQL 和绑定参数。
- 文档与订单为合成演示数据。解析覆盖受控语料里的中文日期和结算表达。未识别的正式条款、跨期却没有一份公告覆盖完整期间、同等权威冲突或循环引用均停止计算。单次最多跟进四次引用。

## 默认执行

1. **固定快路径。** 读基础政策，必要时查第一份公告。条款已明确时直接核验账本并查库，零模型调用。
2. **缓存计划。** 继续转引时，复用当前文档指纹下通过核验的步骤。缓存键包含逻辑版本、数据库、产品、地区、政策文号和正文指纹。每次请求从同一份文档快照取证，重新选择账本并执行 SQL。缓存只保存步骤，进程内最多 128 条。
3. **重新规划。** 未命中时由 DeepSeek 选择剩余的白名单动作。缓存与本次证据不符，或首次计划缺少必要步骤时，保留已查证据，最多向模型再请求一次。内容指纹变化时旧计划不命中。模型不可用时可手动选「确定性遍历」执行当前语料的多层引用。

## 实测

26 个查询范围，各跑三轮。每轮重新创建缓存，用与测评范围不同的开发请求预热，预热单列。各模式共用同一份语料、账本、SQL 执行及判分逻辑。模型组使用 DeepSeek V4 Pro，温度 0。正确金额要求匹配账本、金额、参数、工具顺序和逐条文档引用。缺证据或澄清场景必须在查询前停止。

| 指标 | 原固定单跳 | 确定性多跳 | 每次规划 | 默认自动 |
| --- | ---: | ---: | ---: | ---: |
| 预期结果全通过 | 36/78 | 78/78 | 78/78 | 78/78 |
| 金额和证据通过 | 15/54 | 54/54 | 54/54 | 54/54 |
| 不支持该引用深度并安全停止 | 42 | 0 | 0 | 0 |
| 测评阶段模型调用 | 0 | 0 | 66 | 12 |
| 测评阶段 token | 0 | 0 | 20,055 | 3,750 |
| 测评阶段 P95 | 16.38 ms | 21.25 ms | 2.29 s | 1.41 s |

默认模式命中 30 次计划缓存，另有 15 次金额请求走固定快路径。计入预热的 6 次调用和 1,866 token，默认模式共用 5,616 token，相比每次规划少 72.0%，测评 P95 少 38.4%。四种模式均未返回错误金额或在证据不足时返回金额。确定性多跳同样全通过，在全通过的模式中延迟最低。本次结果支持多跳正文检索和缓存节省规划成本，未观察到模型规划相对确定性多跳的准确率增益。

首轮同一套题用于定位计划边界错误。默认模式通过 76/78，每次规划通过 68/78。失败主要发生在三跳任务，计划到达最终条款后仍要求继续检索。修复后，执行器允许跳过已无后续引用的条件步骤，规划器收到明确的下一步。上表是修复后在同一套题上的回归成绩。

## 缓存失效与重规划核验

独立使用 DeepSeek V4 Pro 运行 2027 年 1 月华南电水壶任务。首次金额为 ¥211.00。复跑命中缓存，模型调用为 0，再执行一次 SQL 得到同样金额。

- 将缓存序列替换成旧单跳步骤后，一次真实重规划完成剩余查询。已找到的第一份公告没有重复检索，只执行一次 SQL，仍得 ¥211.00。
- 在临时文档副本里把最终公告的每笔上限从 ¥7 改为 ¥6。指纹变化触发旧计划失效，重新规划后得到 ¥212.00。同版再跑时零模型调用，仍得 ¥212.00。
- 上述两项为独立故障注入。上表的正常数据复测没有触发重规划。

## 复现

```bash
python -m evaluation.run_hard_policy_comparison --suite text \
  --env-file /path/to/.env --repeats 3 --workers 5 --output-dir /path/to/results
python -m evaluation.run_hard_policy_comparison --suite legacy --modes fixed \
  --repeats 1 --output-dir /path/to/legacy-results
python -m unittest discover -s tests -q
```

启动在线演示后打开[政策探索](http://127.0.0.1:28501/?workspace=policy-exploration)。选「先找指定标题，再找当期公告」并连续提交两次。展开「查看计划与执行」可核对路径及用量，展开证据可查看引用链的原文和行号。
