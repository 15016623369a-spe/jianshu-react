# 见数：作品集案例

## 一句话

面向政策、手册和零售数据的 Evidence-gated Agentic RAG：把自然语言问题变成可复算的数字或有出处的答案，并保留版本、引用、SQL、参数和拒答边界。

## 问题

普通 Text2SQL 能算数，但不一定知道：

- 用哪个版本的政策；
- 哪个公告在生效；
- 退款用订单表还是售后台账；
- 证据不足时该不该拒答；
- 答案能不能回到原文核对。

普通 RAG 能给一段话，但算不出数字，也不容易审计金额。

## 做法

```text
问题
→ 范围解析
→ 政策/公告/手册检索
→ 证据缺口判断
→ 词面补查 / 模型兜底 / 拒答
→ 只读 SQL 或手册章节
→ 金额与引用核验
→ 历史、导出、权限、观测
```

## 边界

```text
内部评测，不是第三方独立评测
未做真实外部用户试点
不是通用 Agentic RAG 平台
不是生产 SaaS
```

## 面试可以讲的三点

1. 为什么不是普通 RAG：数字需要口径、账本、版本和引用。
2. 为什么不是自由 Agent：受控状态机、证据门槛、可拒答、可回归。
3. 为什么可信：150 题 gate、错误出数 0、审批/ACL/观测/备份。
