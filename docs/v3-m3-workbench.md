# V3 M3：首个可试用工作台

日期 2026 年 11 月 19 日。对应产品执行计划的 M3。

## 已实现

### 1. 导航

政策调查新增：

```text
自然语言调查
文档库
调查历史
系统状态
高级实验
  ├─ 按条件查口径
  ├─ 日期分段
  └─ 多源实验
```

原来的实验入口已经收进「高级实验」，旧 deep link 仍可打开对应子页。

### 2. 调查历史

- 历史页按时间列出当前账号的调查；
- 可打开当时保存的结果；
- 展示状态、金额、证据、执行摘要和版本；
- 历史读取不再重新计算。

### 3. 导出

```text
GET /api/v3/investigations/{id}/report.md
GET /api/v3/investigations/{id}/amounts.csv
```

- Markdown 报告包含结论、范围、金额明细、证据和执行摘要；
- CSV 包含场景、期间、账本、上限、订单、毛营收、扣减和净营收；
- 下载前按当前 owner 重新检查权限；
- CSV 使用 UTF-8 BOM，便于表格软件直接打开。

### 4. 文档解析预览和重复上传

```text
POST /api/v2/policy-documents/preview
POST /api/v3/manual-documents/preview
```

- 预览不落库；
- 返回格式、标题、章节数和前几个章节；
- 文档库增加「解析预览（不会上传）」；
- 相同 owner、来源、文件名和摘要的重复上传返回原文档，不再新增重复文档；
- 新版本仍按原规则追加。

### 5. 追问关联

V3 请求支持 `investigation_id`，追问会生成新的调查 ID，并记录父调查 ID。政策澄清面板会保留原问题，只要求补充缺失条件，然后继续同一调查链。

### 6. 系统状态

```text
GET /api/v3/status
```

展示：

- 模型是否配置；
- 政策数据、政策文档、手册文档是否可用；
- 历史是否可用；
- 领域和检索方式；
- 模型不可用时确定性路径仍可用的说明。
